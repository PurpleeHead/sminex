# Sminex

Адаптивный лендинг жилого комплекса Sminex.

## О проекте

Учебный frontend-проект, выполненный по макету.
Основная задача — сверстать адаптивную страницу с использованием семантической HTML-разметки, SCSS и современных подходов к адаптивной верстке.

## Реализовано

- адаптивная верстка для разных разрешений экранов;
- семантическая HTML-разметка;
- стилизация с использованием SCSS;
- организация стилей по блокам;
- БЭМ;
- адаптивные изображения;
- WebP;
- SVG-спрайт;
- подключение локальных шрифтов;
- мобильная версия;
- оптимизация изображений;
- видео-превью.

## Технологии

- HTML5
- SCSS / CSS3
- БЭМ
- SVG
- WebP
- Git / GitHub

## Структура проекта

```text
sminex/
├── css/          # готовые CSS-файлы
├── favicon/      # favicon и web manifest
├── fonts/        # локальные шрифты
├── images/       # изображения и SVG-спрайты
├── scss/         # исходные SCSS-файлы
├── video/        # видео
├── index.html
└── README.md
```
